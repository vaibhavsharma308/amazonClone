## 📱 Frontend Stack
- React + Vite
- React Router for Navigation
- Axios for API Calls
- Context API for State Management
- Lucide Icons
- CSS3 Animations

## 🔧 Backend Stack
- Spring Boot
- Spring Data JPA
- MySQL Database
- RESTful APIs
- JWT Authentication

## 🚀 Getting Started

### Prerequisites
- Node.js >= 14
- Java 11+
- Maven
- MySQL

### Frontend Setup
```bash
cd ecommerce-frontend
npm install
npm run dev
```

### Backend Setup
```bash
cd ecommerce-backend
./mvnw spring-boot:run
```
