# Screenshots

This directory contains screenshots of the e-commerce platform features.

## How to add screenshots:

1. **Homepage**: Shows hero section with product browsing
   - Featured products
   - Category filtering
   - Search functionality
   - Trust badges (Fast Shipping, Secure, 24/7 Support)

2. **Product Detail**: Product information page
   - Product images
   - Price and specifications
   - Add to cart functionality
   - Related products

3. **Shopping Cart**: Cart page
   - Product list with prices
   - Quantity adjustments
   - Cart total
   - Proceed to checkout

4. **Checkout**: Checkout page
   - Shipping information
   - Payment methods
   - Order summary

5. **Seller Dashboard**: Seller management page
   - Add new products
   - Edit existing products
   - View orders
   - Sales analytics

6. **User Authentication**: Login/Signup pages
   - User registration
   - User authentication
   - Error handling

## Screenshot Format
- Use PNG format for best quality
- Resolution: 1920x1080 or higher
- Include descriptive filenames

## Adding Screenshots
Run the application:
```bash
npm run dev  # Frontend
./mvnw spring-boot:run  # Backend
```

Then capture screenshots from: `http://localhost:5174`
